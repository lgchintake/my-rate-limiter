# Gateway

## Services

| Service | Port | Description |
|---------|------|-------------|
| `discovery` | 8080 | The discovery service that manages service registration and discovery in the microservices architecture. |
| `gateway` | 9081 | The main gateway service that handles incoming requests and routes them to the appropriate microservices. |
| `user-service` | 9082 | The user service that manages user-related operations and data. |
